# SRT 字幕时轴修复工具

一个基于 **Node.js + Express + 原生 HTML/CSS/JavaScript** 的 Web 应用，包含三个模块：

1. **时轴修复**：修复 SRT 字幕的显示时间，保护用户指定的场景切点不被字幕跨越，并支持把关键字幕锁定为不可移动的时间锚点。
2. **字幕分卷导出**：把整部字幕按“每卷时长 / 字符数”两项上限切分成多卷，用全局动态规划选择分卷边界，打包 ZIP 下载（卷内时间回零，附 manifest.json）。
3. **字幕智能换行**：按“每行最大显示宽度 / 最多行数”为字幕重新分行，按字素簇计算显示宽度，用动态规划在空白与标点后的合法位置选择断点；无法在行数内消除超限的字幕会被标出并拒绝导出。

页面顶部导航可在三个模块之间切换。

## 功能

### 时轴修复（首页 `/`）

- 上传 UTF-8 编码的 `.srt` 字幕文件。
- 输入一条或多条不可跨越的场景切点：
  - 支持秒：`12.5`
  - 支持 `分:秒`：`01:30.500`
  - 支持完整 SRT 时间：`00:01:30,500`
  - 可换行，也可用逗号、分号分隔。
- 输入要锁定的字幕编号（可选）：
  - 编号按字幕在文件中的顺序从 1 开始（即结果表中的 `#` 列）；
  - 可用逗号、空格或换行分隔，例如 `3, 7, 12`；
  - 锁定字幕严格保留原始起止时间，不参与最短时长/CPS 延长，也不会被移动；
  - 锁定字幕作为**双向时间锚点**参与约束传播：前序字幕必须在锚点开始前让位，后续字幕必须在锚点结束后排布。
- 同时联动满足：
  - 每条未锁定字幕的最短显示时长；
  - 最大每秒字符数（CPS）；
  - 相邻字幕之间的最小间隔；
  - 原有字幕顺序；
  - 字幕不得开始于切点之前且结束于切点之后。
- 有解时在全部可行解中最小化整体时移（最小二乘意义），提供修复前后对照表（锁定行有标记），并下载与预览一致的修复后 SRT。
- 无解时在页面中红色高亮造成冲突的**最短连续字幕段**（包含相关锚点），并给出：
  - 最少需要的时间；
  - 可用时间；
  - 超出时间；
  - 冲突涉及的锁定字幕编号；
  - 是单条时长不足、连续字幕容量不足、切点两侧顺序冲突，还是锁定字幕覆盖切点。

### 字幕分卷导出（`/split.html`）

- 复用同一套 SRT 解析与可见字符统计（忽略标签、ASS 覆盖与空白）。
- 用户设置每卷上限：最长 **1～30 分钟**、最多 **100～20000 字**。
- 每卷是字幕序列中连续的一段，**分卷边界只能落在相邻字幕之间**，绝不拆分单条字幕。
- 每卷需同时满足：卷内时长（末条结束 − 首条开始）≤ 时长上限，且可见字符总数 ≤ 字符上限。
- **全局动态规划**（不是从头装满的贪心）在所有满足两项上限的方案中依次优化：
  1. 分卷数最少；
  2. 所有边界处的字幕间隔（下一条开始 − 上一条结束）总和最大；
  3. 同分时取更早的边界序列（边界位置字典序最小）。
- 单条字幕自身超限（时长或字符数超过每卷上限）时，列出编号与原因并**拒绝导出**。
- 结果页预览每卷的原始时间范围、字幕数与字符数。
- 下载 ZIP：每卷一个独立 SRT，**卷内时间统一回零**（从 `00:00:00,000` 开始）；附 `manifest.json` 记录每个卷文件名与原始时间范围。

### 字幕智能换行（`/wrap.html`）

- 复用同一套 SRT 解析；编号、时轴与样式标记（HTML 标签、ASS 覆盖块）原样保留，仅替换文本行。
- 用户设置：每行最大显示宽度（4～200 的整数，默认 40）、最多行数（1～10 的整数，默认 2）。
- 显示宽度按**字素簇**（grapheme cluster）计算：
  - 中文及全角字符计 2；
  - 其他可见字符计 1；
  - HTML 标签（如 `<i>`、`<font ...>`）与 ASS 覆盖块（如 `{\an8}`）计 0，且作为整体**不可从内部断开**；
  - 行内空白按字符计入（半角空格 1、全角空格 2），行首/行尾空白不计宽。
- 合法断点：空白游程之后，或句读标点（`，。、；：？！…—）】》」』` 等）之后；标签、覆盖块与单词内部不可断开。字幕中原有的换行作为强制断点保留，并计入最多行数。
- 每条字幕用**动态规划**选择断点，依次最少化：
  1. 超限宽度（各行超出每行最大宽度的总量）；
  2. 行宽极差（最宽行与最窄行的宽度之差）；
  3. 断点数；
  4. 同分取更早的断点序列。
- 预览展示每条字幕换行前后的各行文本与行宽（超限行红色标出）；无法在最多行数内消除超限的字幕会被标出并**拒绝导出**。
- 全部可行时下载新 SRT（带 BOM），编号、时轴与样式标记保持不变。

## 使用 Docker Compose 启动

要求本机已安装 Docker 与 Docker Compose。

```bash
docker compose up --build
```

该命令会自动：

1. 构建 Node.js 镜像；
2. 执行 `npm ci --omit=dev` 安装生产依赖；
3. 启动 Express 服务。

启动后在浏览器打开：

- <http://localhost:3000/> — 时轴修复
- <http://localhost:3000/split.html> — 字幕分卷导出
- <http://localhost:3000/wrap.html> — 字幕智能换行

后台运行：

```bash
docker compose up --build -d
```

停止：

```bash
docker compose down
```

## 页面参数

### 时轴修复

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 最短显示时长 | `0.5` 秒 | 每条未锁定字幕至少显示的时间 |
| 最大 CPS | `15` 字符/秒 | 字幕时长至少为 `字符数 / CPS`，向上取整到毫秒 |
| 最小间隔 | `80` 毫秒 | 上一条结束到下一条开始之间至少保留的时间 |
| 场景切点 | 空 | 字幕时间不得覆盖的切点列表 |
| 锁定字幕编号 | 空 | 保留原始起止时间的字幕编号（从 1 开始），可用逗号、空格或换行分隔 |

### 字幕分卷导出

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 每卷最长 | `25` 分钟 | 1～30 分钟；卷内时长 = 末条结束 − 首条开始 |
| 每卷最多字符 | `8000` 字 | 100～20000 字；按可见字符统计 |

字符数统计会忽略：

- 字幕标签，例如 `<b>...</b>`、`<font ...>...</font>`；
- ASS 风格覆盖，例如 `{\an8}`；
- 空白字符。

中日韩文字和拉丁字符均按一个可见字符计算。

### 字幕智能换行

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 每行最大显示宽度 | `40` | 4～200 的整数；中文及全角计 2、其他可见字符计 1（20 个汉字 ≈ 宽度 40） |
| 最多行数 | `2` | 1～10 的整数；含字幕中原有的换行 |

## 调整算法说明

每条未锁定字幕 i 的最低时长为：

```text
required_i = max(原始时长, 最短显示时长, ceil(字符数 × 1000 / 最大CPS))
```

锁定字幕的占用区间固定为原始时长（不延长、不移动）。

设相邻字幕最小间隔为 `gap`，则调整后的开始时间必须满足：

```text
start_i + required_i + gap <= start_(i+1)
```

对于切点 `cut`，字幕不能满足 `start < cut < end`。系统先按每条字幕的原始中点决定它属于切点左侧还是右侧；该归属允许调整相邻边界，但不允许字幕越过切点。

求解时把开始时间转换为累计偏移后的单调序列，在每个切点区间的上下界内做有界单调回归，使开始时间整体尽量少偏离原始时轴。

### 锁定字幕（双向时间锚点）

锁定编号后，该字幕的开始时间在求解器中被钉死为原始值（下界 = 上界 = 原始开始时间），等效于单调链上的点约束，随有界单调回归向两侧传播——不是先求解再覆盖时间：

- 前序字幕必须在 `锚点开始 − 最小间隔` 之前结束，可能被整体提前；
- 后续字幕必须在 `锚点结束 + 最小间隔` 之后开始，可能被整体推后；
- 目标函数不变：在全部可行解中最小化整体时移（最小二乘意义）。

### 无解诊断

无解的必要条件可表示为某一段连续字幕的最低时间需求超过其允许范围（允许范围的端点可以是时间轴起点、切点或锁定锚点）。系统扫描最短窗口并返回包含相关锚点的最小冲突段：

- 单条字幕无法放入所在切点区间时，只标这一条；
- 多条字幕连续联动后容量不足时，返回最短连续段，并列出段内冲突的锁定字幕；
- 原始中点归属导致顺序反转时，标出相邻的两条；
- 锁定字幕的原始区间覆盖切点时，单独标出该锁定字幕，说明锁定时长与切点内侧可容纳的跨度。

## 分卷算法说明

一卷是字幕序列中连续的一段 `[i, j)`，需同时满足：

```text
cues[j-1].end - cues[i].start <= maxDurationMs      （卷内时长上限）
sum(cues[i..j).chars) <= maxChars                   （卷内字符上限）
```

分卷边界只能落在相邻字幕之间。求解使用自后向前的全局动态规划：`dp[i]` 表示第 i 条（含）到末尾字幕的最优划分，候选首卷为 `[i, j)`，转移时按以下字典序目标比较：

1. `volumes` 小者优先（分卷数最少）；
2. `gapSum` 大者优先（边界处字幕间隔总和最大）；
3. 首刀位置 `j` 小者优先（边界序列字典序最小，即“同分取更早的边界序列”）。

因为候选边界序列都以 `j` 开头，第三级平局只需 O(1) 比较首刀位置，后缀最优性由 `dp[j]` 保证——这与“从头装满当前卷再切下一卷”的贪心不同：贪心只局部最大化当前卷的装入量，既不保证卷数最少，也不保证边界间隔总和最大。

单条字幕若自身超过任一上限，则任何划分都无法容纳它：接口返回该字幕的编号与具体原因（时长或字符数超限），并拒绝导出。

### 导出产物

ZIP 内包含：

```text
<基础名>.part01.srt      # 第 1 卷，卷内时间统一回零（减去卷首字幕的原始开始）
<基础名>.part02.srt      # 第 2 卷
...
manifest.json            # 清单
```

`manifest.json` 示例：

```json
{
  "source": "movie.srt",
  "generatedAt": "2026-09-19T12:00:00.000Z",
  "options": { "maxMinutes": 25, "maxChars": 8000, "maxDurationMs": 1500000 },
  "volumeCount": 2,
  "totalGapMs": 4200,
  "volumes": [
    {
      "file": "movie.part01.srt",
      "cueCount": 120,
      "charCount": 3456,
      "firstCueIndex": 1,
      "lastCueIndex": 120,
      "durationMs": 1499000,
      "originalRange": {
        "startMs": 0,
        "endMs": 1499000,
        "start": "00:00:00,000",
        "end": "00:24:59,000"
      }
    }
  ]
}
```

ZIP 由内置的极简写入器生成（STORE 存储模式，UTF-8 文件名），不引入外部依赖。

## 换行算法说明

### 词法单元与宽度

每条字幕文本先被切成词法单元序列：

- **atom**：单个字素簇（`Intl.Segmenter` 的 grapheme 切分，组合字符与 Emoji 序列不会从中间断开），或一个 HTML 标签 / ASS 覆盖块（与解析器相同的 `<[^>]*>`、`\{[^}]*\}` 规则）；
- **space**：连续空白游程（不含换行）；
- **newline**：原文件已有的换行，作为强制断点。

宽度规则：atom 中含中文/全角码位计 2，其他可见字符计 1，标签与覆盖块计 0；行首/行尾的空白不计入行宽（断行落在空白游程处时整段空白被吸收）。

### 合法断点

行末只能落在：

1. 空白游程之后；
2. 句读标点之后（`，。、；：？！…—～）】》」』’”` 及常见 ASCII 标点）；
3. 强制换行处（原样保留，不额外计断点）；
4. 文本末尾。

标签、覆盖块与单词内部都不是合法断点，因此样式标记永远不会被拆散。

### 动态规划

`dp[i][k]` 表示用词法单元 `i..` 排成恰好 `k` 行的 Pareto 前沿，每个状态记录
`(总超限宽度 o, 最窄行宽 mn, 最宽行宽 mx, 断点决策链)`。转移时枚举本行行末的合法断点，
与后缀前沿合并；若某状态在 `o`、`mn`、`mx` 上都不劣于另一状态且断点序列不晚，则另一状态被安全剪枝。
最终在 `k ≤ 最多行数` 的状态中按字典序取最优：

```text
超限宽度 Σ max(0, 行宽 − 每行最大宽度)   小者优先
行宽极差 = 最宽行 − 最窄行               小者优先
行数（即断点数 + 1）                     少者优先
断点位置序列                             更早者优先
```

若最优解的超限宽度仍大于 0（典型原因：无空白无标点的长串不可断行，或行数上限太紧），
该字幕被标为超限；只要存在超限字幕，接口返回 422 与失败清单并拒绝导出。
单条字幕超过 1000 个字素簇时返回 400（防止病态输入拖垮求解）。

### 导出产物

成功时响应中的 `wrappedSrt` 是完整的新 SRT：编号从 1 顺序保留、时轴逐毫秒不变、
样式标记原位保留，仅文本被替换为换行后的各行；前端加 BOM 后下载为 `<基础名>.wrapped.srt`。

## HTTP 接口

### `POST /api/fix`

`multipart/form-data`：

- `subtitle`：SRT 文件；
- `minDurationSeconds`：最短显示时长（秒）；
- `maxCps`：最大每秒字符数；
- `minGapMs`：最小间隔（毫秒）；
- `cuts`：切点文本；
- `locks`：锁定字幕编号文本（可选，从 1 开始，逗号/空格/换行分隔）。

返回：

- `200`：有解，包含原始字幕、修复后字幕（每条带 `locked` 标记）、顶层 `lockedIndices`、序列化后的 SRT 与统计信息（含 `locked` 数量）；
- `422`：字幕可解析但约束无解，包含最短冲突段及原因；`conflict.lockedIndices` 列出冲突涉及的锁定字幕；
- `400`：文件缺失、SRT 格式错误、参数无效或锁定编号不存在。

健康检查：

```bash
curl http://localhost:3000/api/health
```

带锁定字幕的调用示例：

```bash
curl -F "subtitle=@movie.srt" \
     -F "cuts=12.5, 01:30.500" \
     -F "locks=3, 7, 12" \
     http://localhost:3000/api/fix
```

### `POST /api/split`

分卷预览。`multipart/form-data`：

- `subtitle`：SRT 文件；
- `maxMinutes`：每卷最长分钟数（1～30，可带小数，缺省 25）；
- `maxChars`：每卷最多字符数（100～20000 的整数，缺省 8000）。

返回：

- `200`：`volumeCount`、`totalGapMs` 与 `volumes` 数组，每卷含 `fileName`、原始时间范围（`start`/`end`/`startMs`/`endMs`）、`cueCount`、`charCount` 与 `gapAfterMs`；
- `422`：存在自身超限的单条字幕，`oversizedCues` 列出编号、时长、字符数与原因（`reasons`），拒绝导出；
- `400`：文件缺失、SRT 格式错误或参数越界。

### `POST /api/split/download`

参数与 `/api/split` 相同。返回：

- `200`：`application/zip` 附件（`<基础名>.volumes.zip`），内含：
  - `<基础名>.part01.srt`、`part02.srt`……：卷内时间统一回零的 SRT（带 BOM，编号从 1 重新计数）；
  - `manifest.json`：记录源文件名、参数、分卷数、边界间隔总和，以及每卷的 `file` 与 `originalRange`（原始范围，毫秒与 `HH:MM:SS,mmm` 两种表示）；
- `422` / `400`：与预览接口一致（JSON 错误）。

```bash
curl -F "subtitle=@movie.srt" \
     -F "maxMinutes=25" \
     -F "maxChars=8000" \
     http://localhost:3000/api/split

curl -F "subtitle=@movie.srt" \
     -F "maxMinutes=25" \
     -F "maxChars=8000" \
     -o movie.volumes.zip \
     http://localhost:3000/api/split/download
```

### `POST /api/wrap`

智能换行预览与导出。`multipart/form-data`：

- `subtitle`：SRT 文件；
- `maxWidth`：每行最大显示宽度（4～200 的整数，缺省 40）；
- `maxLines`：最多行数（1～10 的整数，缺省 2）。

返回：

- `200`：`results` 含每条字幕的换行前后对照（`originalLines` / `lines`，每行带文本与行宽）、`overflow`、`range`、`breaks`、`lineCount`、`changed`、`feasible`；`wrappedSrt` 为换行后的完整 SRT（保留编号、时轴与样式标记），前端据此生成下载；
- `422`：存在无法在最多行数内消除超限的字幕，`failedCues` 列出编号、剩余超限与原因，`results` 仍给出全部字幕的最佳尝试，拒绝导出（无 `wrappedSrt`）；
- `400`：文件缺失、SRT 格式错误、参数越界，或单条字幕超过 1000 个字素簇。

```bash
curl -F "subtitle=@movie.srt" \
     -F "maxWidth=40" \
     -F "maxLines=2" \
     http://localhost:3000/api/wrap
```
